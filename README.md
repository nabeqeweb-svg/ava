# AVA — آوا

Persian Text-to-speech web app.

## Features
- High-quality Persian TTS (Edge voices)
- Number and time expansion in Persian
- RTL UI with Vazirmatn font
- Local draft & history

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:8080

## Stack
- TanStack Start + React 19
- Vite + Tailwind CSS 4
- better-auth + PGlite
- Edge TTS
