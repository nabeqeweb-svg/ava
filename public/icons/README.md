# PWA Icons

برای تبدیل به APK این آیکون‌ها لازم هستند:

- `icon-192.png` (۱۹۲×۱۹۲)
- `icon-512.png` (۵۱۲×۵۱۲)
- `icon-192-maskable.png` (۱۹۲×۱۹۲ با padding مناسب)
- `icon-512-maskable.png` (۵۱۲×۵۱۲ با padding مناسب)

می‌توانید از سایت‌هایی مثل https://www.pwabuilder.com/imageGenerator یا https://realfavicongenerator.net استفاده کنید.

فعلاً از favicon.svg به عنوان جایگزین استفاده می‌شود.
